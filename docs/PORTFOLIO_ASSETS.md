*Every asset listed below **exists in this repository** and was inspected during the portfolio
pass. Nothing here is fabricated, and no stock or generic image is substituted for a project
visual. §3 lists what does not exist and must be captured manually.*

## 1 · What exists

The repository contains **no rendered images, screenshots or photographs**.
`portfolio/renders/` holds a single `.gitkeep`.

What it does contain is **14 generated drawing sheets** — SVG and PDF, produced deterministically
by `drawings/generate.py`, every dimension carrying a provenance entry. These are real
engineering artifacts, not illustrations, and they are the correct visuals for this project.

### Notes on use

- **SVG over PDF for the web.** GitHub renders repository SVGs inline; the PDFs are the release
  record. Both are byte-identical to what `drawings/generate.py` produces.
- The drawing sheets are **white-background line drawings**. They read correctly in a light
  theme and remain legible in a dark one, but if a dark-theme presentation matters, capture #3
  below.
- **Do not crop a title block off** a drawing used as a portfolio visual. The title block carries
  the revision and date, and a drawing without it looks like an illustration rather than a
  released document.
