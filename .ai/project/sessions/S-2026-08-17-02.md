## Work performed

1. **The canonical path is now enforced structurally, not only by tests.** `run()` re-derives
   the prefix measurement from the octets it actually emitted, immediately before the only
   writes that leave the process, and halts on any disagreement. A branch that skips,
   fabricates, truncates or mis-caps the measurement cannot reach a canonical write.
2. **Five mutations applied to `build.py` for real and confirmed caught** — M8, M9, M10 (first
   round) and **M11, M12, M13** (second). M11 and M13 are killed by the post-condition; M12 by
   a test that moves the declared cap in memory and requires the measurement to follow, which
   is the difference between asserting a value and asserting a provenance.
3. **`TCR-002` F-7 repaired**, not merely routed: a `BudgetBreach` now returns a structured
   `BuildOutcome(status="HALT")` from `run()` instead of propagating, so a caller can tell
   *did not run* from *halted on a breach*. The exception type is unchanged for the direct
   callers the certification suite asserts on.
4. **The clone defect fixed.** 35 exec-layer tests carried no `needs_artifacts` guard and
   hard-failed without the untracked tokenizer artifacts. Guarded per test: **35 fail → 35
   skip**. `README.md` now publishes the measured clone numbers and how to provision the
   artifacts, and a `validate` workflow runs the battery on GitHub's runners — where there is
   no author's machine to be lucky on.
5. **Four false statements withdrawn where they stood**: `ECR-D-015`'s byte identity,
   `ECR-Q-014`'s *"the only place"*, `ECR-D-016`'s *"to the digit"*, and
   `STATE_REGISTER.md`'s `last_ledger_seq` and exec-layer head — the last two false on the day
   the file was created.
6. **`LICENSE` corrected on two points of fact.** §1's boundary was not exhaustive (six files
   in neither column, now MIT with a stated reason); §2's *"nothing in the set is copyleft"*
   was wrong — `certifi` is MPL-2.0 in the transitive closure. **The conclusion survives on the
   correct ground**: nothing is vendored, modified or redistributed, so no obligation attaches.
7. **`C-1`, `C-2`, `C-3` ratified and `C-5` closed** — `CONTRIBUTING.md` is no longer a
   placeholder, and CI exists.
8. **`ECR-D-016`'s Rev B candidate carries its own defects now** (§7): the ≈22 mm creepage
